Assessment API Spec

POST /api/v1/assess

Submit a list of biological indicators to match against the trained classifier network.

// Request Payload

{

"symptoms": ["itching", "skin_rash", "fatigue"]

}


// Response Payload

{

"disease": "Fungal infection",

"confidence": 92.4,

"recommendations": ["Avoid scratching", "Keep area clean"]

}
